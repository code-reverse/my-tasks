# My Tasks

Расширение для VS Code, позволяющее добавлять задачи с приоритетом, отмечать их выполнение и смотреть статистику

## Возможности

* Добавление и удаление задач
* Приоритет задач: !, !! или !!!
* Отметка задач как выполненных и их повторная активация
* Сохранение задач между сеансами работы
* Отображение невыполненных задач в начале списка, по убыванию приоритета
* Отображение количества невыполненных задач
* Окно статистики с графиком выполненных задач за последние 7 дней

## Использование

1. Откройте Explorer и найдите раздел "My Tasks"
2. Нажмите "+", чтобы создать новую задачу
3. Введите название задачи и нажмите Enter
4. Используйте чекбокс, чтобы отметить задачу как выполненную или вернуть ее в активное состояние
5. Нажмите на задачу, чтобы сменить приоритет: ! → !! → !!! → !
6. Наведите курсор на задачу и нажмите на значок корзины, чтобы удалить ее
7. Нажмите на значок графика в заголовке раздела, чтобы открыть статистику

## Сборка

```sh
npm run package
```

## Установка

В VS Code откройте раздел расширений, нажмите на "..." и выберите "Install from VSIX"

Выберите созданный файл с расширением `.vsix`
